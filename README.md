# Roof Rush

A free, mobile-friendly roofing game by **Cloudy**. Rip off the old shingles, roll out the underlayment, and nail new shingle rows in line before the storm rolls in. Earn money, upgrade your tools, hire a crew, and work your way up from a garden shed to a grand mansion.

Play: https://itscloudy96.github.io/roof-rush/

- Single page HTML/CSS/JS, no build step, no dependencies, no tracking
- Portrait touch controls (mouse works too); progress saved in localStorage
- Sound is optional and off by default
- MIT licensed. Fork it, reskin it, make it yours.
